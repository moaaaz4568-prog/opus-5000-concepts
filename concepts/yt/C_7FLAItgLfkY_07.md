# وكيل تحليل الفواتير: OCR واستخراج متغيرات ثم قاعدة بيانات ثم إشعار فريق الفوترة

**التصنيف:** مفهوم — وكلاء ذكاء اصطناعي / الفوترة (حالة الاستخدام السابعة من ثماني حالات في الفيديو).

**المصدر الرئيسي:** S_yt_7FLAItgLfkY_ar.

## ملخص
«وكيل الذكاء الاصطناعي لتحليل الفواتير. يبدأ الأمر بفاتورة… تتكون من بيانات العقار، والشخص، واسم الشركة، والعنوان، والبريد الإلكتروني، ورقم الفاتورة». الجدولة: «سيتم تشغيل هذا ربما كل يومين، كل أسبوعين». عند التشغيل: «تنزيل الملف… استخراج المعلومات أو النص من الملف. سيستخرج جميع المتغيرات المختلفة. إذن، بند الفاتورة، رقم الفاتورة»، «سيضيفها إلى قاعدة بيانات الفواتير»، ثم «باستخدام وكيل الذكاء الاصطناعي، سيقوم بإنشاء بريد إلكتروني يمكننا إرساله بعد ذلك إلى فريق الفوترة لإبلاغهم بأنه تم تحليل الفاتورة». مثال المخرج: «الفاتورة رقم 109 من لوكاس مارتن… وهي تحتوي على جميع التفاصيل» مع «رابطًا لجدول بيانات جوجل، والذي يحتوي على التفاصيل الفعلية». صيغة الاستخراج: «Par ببساطة يعني أننا أخذنا الفاتورة، واستخرجنا كل النص، واستخرجنا المتغيرات الموجودة داخل هذا النص مثل الاسم، واسم الشركة، والبريد الإلكتروني… ثم يمكنك استخدامها لإضافتها إلى قاعدة بيانات أو إرسال بريد إلكتروني». القيمة: «يوفر مئات الساعات للشركات التي تقوم بإصدار الفواتير بشكل منتظم».

## مكونات المفهوم
1. فتح النص ثم استخراج المتغيرات: من الفاتورة إلى «كل النص» ثم إلى حقول مسماة (الاسم، رقم الفاتورة، البنود).
2. قاعدة بيانات الفواتير: كل متغير يُخزَّن بصف مركزي يرتبط برقم الفاتورة.
3. جدولة دورية: تشغيل «كل يومين، كل أسبوعين» بدل المعالجة اليدوية عند كل وصول.
4. إشعار قابل للتحقق: بريد لفريق الفوترة يضم التفاصيل ورابط جدول البيانات الأصلي.

## الأخطاء القاتلة
| الخطأ | لماذا يقتل | البديل |
| --- | --- | --- |
| إبقاء الفواتير نصوصًا غير مهيكلة | «استخرجنا المتغيرات الموجودة داخل هذا النص» هو ما يجعلها قابلة للأتمتة | استخراج حقول معيارية إلى قاعدة بيانات |
| إشعار بلا رابط للتفاصيل | الفريق يحتاج «التفاصيل الفعلية» في جدول البيانات ليتحقق | بريد يجمع الملخص ورابط المصدر |
| تشغيل غير منتظم | الشركات «التي تعالج الفواتير على أساس ربع سنوي أو يومي» تحتاج جدولة صريحة | تشغيل مجدول (يومين/أسبوعين) |
